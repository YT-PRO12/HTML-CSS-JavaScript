# JavaScript Engineering Learning


A structured JavaScript journey from fundamentals to production-style applications.

> **Learn → Build → Refactor → Test → Document**

This repository is intentionally organized as an engineering lab rather than a collection of random tutorial files.

## Roadmap

| Level | Focus | Build |
|---|---|---|
| 01 | Fundamentals | Console programs |
| 02 | Core JavaScript | Utilities & data processing |
| 03 | DOM & Browser APIs | Interactive mini apps |
| 04 | Async JavaScript | API-driven applications |
| 05 | Modern JavaScript | Modules, classes, patterns |
| 06 | Architecture | Reusable services |
| 07 | Advanced JS | Event loop, closures, performance |
| 08 | Testing | Unit & integration-style tests |
| 09 | Full Stack JS | REST API + frontend |
| 10 | Advanced Projects | Production-style applications |

## How to use

Each folder contains:
- `README.md` — concepts and goals
- source files
- exercises
- project README where applicable

Run simple files with:

```bash
node filename.js
```

For Node projects:

```bash
npm install
npm run dev
```

## Skills covered

JavaScript fundamentals • ES6+ • DOM • Events • Async/Await • Fetch • Promises • Modules • OOP • Functional programming • Error handling • Browser storage • REST APIs • Node.js • Express • Authentication concepts • Testing • Design patterns • Performance • Git/GitHub

## Goal

The goal is not to memorize JavaScript syntax.

The goal is to become capable of designing, debugging and shipping JavaScript applications.
