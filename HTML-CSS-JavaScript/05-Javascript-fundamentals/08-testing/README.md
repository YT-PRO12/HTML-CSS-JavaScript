# 08 — Testing

Professional JavaScript is not only about writing code.

It is also about knowing whether the code keeps working.

## Learn

- Unit testing
- Assertions
- Test cases
- Edge cases
- Mocking
- Integration testing concepts
- Test-driven development basics

Recommended tool: Vitest

## Test checklist

For every utility:

- Normal input
- Empty input
- Invalid input
- Boundary values
- Error behavior
- Regression case
