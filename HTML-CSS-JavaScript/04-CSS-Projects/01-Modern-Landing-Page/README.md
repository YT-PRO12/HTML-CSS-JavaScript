# Modern Landing Page

A responsive landing page built with HTML5 and CSS3.

## Features
- Responsive navbar
- Hero section
- Feature cards
- Pricing section
- About section
- Flexbox and CSS Grid
- CSS variables
- Hover effects
- Transitions and transforms
- Responsive media queries
- clamp(), min() and max()

## Technologies
- HTML5
- CSS3

## Purpose
