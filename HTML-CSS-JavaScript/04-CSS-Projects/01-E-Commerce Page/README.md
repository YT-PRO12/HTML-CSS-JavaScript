# E-commerce Homepage

A beginner-friendly but professional e-commerce homepage built using HTML5 and CSS3.

## Features

- E-commerce style navigation bar
- Search bar
- Account and cart section
- Category cards
- Featured product cards
- Add to cart buttons
- Deals section
- Responsive footer
- Hover effects
- CSS transitions
- Flexbox
- CSS Grid
- CSS variables
- Media queries
- Responsive design

## Technologies

- HTML5
- CSS3

## Purpose

This project combines CSS fundamentals into a practical e-commerce webpage. It is intentionally kept simple enough to understand while demonstrating real-world layout and responsive design techniques.
