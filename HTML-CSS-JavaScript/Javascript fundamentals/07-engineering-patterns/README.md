# 07 — Engineering Patterns

Turn language knowledge into reusable engineering tools.

## Implement from scratch

### Event Bus
Publish/subscribe communication between modules.

### Debouncer
Useful for search boxes and expensive UI operations.

### Rate Limiter
Restrict how frequently an operation can execute.

### In-Memory Cache
Store expensive results temporarily with TTL.

### Job Queue
Process asynchronous tasks in a controlled order.

### Repository Pattern
Separate data access from business logic.

### Service Layer
Keep business rules independent from HTTP handlers.

These projects are intentionally small so the underlying design is visible.
