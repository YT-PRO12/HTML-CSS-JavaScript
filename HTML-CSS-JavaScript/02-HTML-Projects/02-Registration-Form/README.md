# Student Registration Form

A student registration form built using HTML5 to demonstrate different
HTML form elements and input types.


## Features

- Personal information section
- Email and password inputs
- Phone number input
- Date of birth selection
- Gender selection
- Course selection
- College and year of study
- Technical skills selection
- Address field
- Resume upload
- Terms and conditions
- Register and Reset buttons

## HTML Concepts Used

- HTML5
- Forms
- Labels
- Text inputs
- Email input
- Password input
- Telephone input
- Date input
- Radio buttons
- Checkboxes
- Select and option
- Textarea
- File upload
- Fieldset and legend
- Buttons
- HTML form validation

## Technologies Used

- HTML5
