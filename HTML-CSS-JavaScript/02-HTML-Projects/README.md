# HTML Projects

This section contains small projects built using HTML5 to demonstrate
practical understanding of HTML structure, semantic elements, forms,
tables, links, navigation and webpage organization.

## Projects

| # | Project | Description |
|---|---|---|
| 01 | Personal Portfolio | A personal portfolio webpage containing About, Skills, Projects, Education and Contact sections. |
| 02 | College Website | A college website structure containing courses, faculty, admissions and contact information. |
| 03 | Registration Form | A student registration form demonstrating different HTML form elements and input types. |

## Concepts Demonstrated

- HTML5 Structure
- Semantic HTML
- Headings and Paragraphs
- Links and Navigation
- Lists
- Tables
- Forms
- Input Types
- Images
- Multimedia
- `div` and `span`
- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`
- Form Validation using HTML attributes

## Technologies Used

- HTML5

## Purpose

The purpose of these projects is to apply the HTML fundamentals learned
in the previous section and build complete webpage structures using
HTML5.

## Note

These projects currently focus on HTML structure and functionality.
Styling and interactivity will be added later using CSS and JavaScript.
